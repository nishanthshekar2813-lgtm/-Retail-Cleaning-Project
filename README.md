# 🧹 Smart Retail Data Cleaning & Visualization

## 📌 Overview
This project focuses on cleaning and analyzing retail data using Python.

## 🔧 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Tasks Performed
- Handled missing values
- Removed duplicates
- Feature engineering
- Data visualization

## 📈 Insights
- Electronics generate highest revenue
- Bangalore & Mumbai show high sales
- Discounts influence purchase behavior

## 🚀 Outcome
Learned data preprocessing and visualization techniques.
